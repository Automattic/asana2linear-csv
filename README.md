# Asana to Linear CSV Transformer

A utility for transforming CSV files exported from Asana into a format that can be imported into Linear using Linear's import CLI tool.

## Introduction

This tool facilitates the migration of projects from Asana to Linear by transforming the CSV data format. Linear's import tool requires a specific CSV format, and this transformer handles the mapping of fields, statuses, priorities, and labels between the two systems.

The transformer is particularly useful when you need to migrate projects one by one rather than doing a complete migration all at once. It preserves important metadata like task status, priority, assignees, and custom fields.

## Features

- Maps Asana fields to Linear fields
- Transforms status values to match Linear's workflow states
- Converts priorities from Asana to Linear format
- Handles custom fields and transforms them into Linear labels

## Requirements

- PHP 7.4 or higher
- CSV file exported from Asana

## Installation

1. Clone this repository:
   ```
   git clone https://github.com/Automattic/asana2linear-csv.git
   cd asana2linear-csv
   ```

## Usage

### Exporting from Asana

1. In Asana, go to the project you want to export
2. Click on the project actions menu (three dots)
3. Select "Export" and then "CSV"
4. Save the CSV file to your computer

### Running the Transformer

Use the command-line interface to transform your CSV file:

```
php csv_transformer.php input-file.csv output-file.csv
```

### Importing into Linear

Use the output file generated by this transformer to import tasks into Linear using its CLI tool and choosing the "Linear (CSV export)" option.
