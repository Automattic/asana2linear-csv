# Asana to Linear CSV Transformer

A utility for transforming CSV files exported from Asana into a format that can be imported into Linear using Linear's import CLI tool.

## Introduction

This tool facilitates the migration of projects from Asana to Linear by transforming the CSV data format. Linear's import tool requires a specific CSV format, and this transformer handles the mapping of fields, statuses, priorities, and labels between the two systems.

The transformer is particularly useful when you need to migrate projects one by one rather than doing a complete migration all at once. It preserves important metadata like task status, priority, assignees, and custom fields.

## Features

- Maps Asana fields to Linear fields
- Transforms status values to match Linear's workflow states
- Converts priorities from Asana to Linear format
- Handles custom fields and transforms them into Linear labels

## Requirements

- PHP 7.4 or higher
- CSV file exported from Asana

## Installation

1. Clone this repository:
   ```
   git clone https://github.com/Automattic/asana2linear-csv.git
   cd asana2linear-csv
   ```

## Usage

### Exporting from Asana

1. In Asana, go to the project you want to export
2. Click on the project actions menu (three dots)
3. Select "Export" and then "CSV"
4. Save the CSV file to your computer

### Configuration

The transformer requires a configuration file that defines the field mappings between Asana and Linear. You can create custom configuration files for different projects or teams.

The configuration file contains:

- `base_mapping`: Maps Linear fields to Asana fields
- `fields_mapping`: Transforms field values (e.g., priorities, statuses)
- `labels_mapping`: Converts Asana fields to Linear labels
- `field_handlers`: Custom handlers for special field transformations

A default configuration for Newspack projects is provided in `newspack.php`.

### Running the Transformer

Use the command-line interface to transform your CSV file:

```
php csv_transformer.php input-file.csv output-file.csv config-file.php
```

Example:
```
php csv_transformer.php asana_export.csv linear_import.csv newspack.php
```

### Importing into Linear

Use the output file generated by this transformer to import tasks into Linear using its CLI tool and choosing the "Linear (CSV export)" option.

## Creating Custom Configurations

You can create custom configuration files for different projects or teams. Simply create a new PHP file that returns an array with the required mappings:

```php
<?php
return [
    // The base mapping from Linear fields to Asana fields.
    'base_mapping' => [
        // Linear => Asana field mappings
    ],
    // For fields mapped in the base_mapping that need to have their values mapped and transformed.
    'fields_mapping' => [
        // Field value transformations
    ],
    // For Asana custom fields that should be mapped to Linear Labels
    'labels_mapping' => [
        // Label mappings
    ],
    // For Asana custom fields that needs special treatment (for exmaple, appending to the description)
    'field_handlers' => [
        // Custom field handlers as anonymous functions
        'Some Asana Field' => function($input, $output, $transformer) {
            // Transform the input and modify the output row
            // $transformer provides access to helper methods
            return $output;
        },
    ],
];
```

Then run the transformer with your custom config:

```
php csv_transformer.php input.csv output.csv my-custom-config.php
```

### Custom Field Handlers

Field handlers allow you to perform custom transformations on specific fields. You can define them as anonymous functions in your configuration file:

```php
'field_handlers' => [
    'P2 or Slack thread [Newspack Product]' => function($input, $output, $transformer) {
        // Get the index of the Description field
        $descriptionIndex = $transformer->getOutputFieldIndex('Description');

        // Append the P2 or Slack thread to the description
        if (!empty($input)) {
            $output[$descriptionIndex] .= "\n\nP2 or Slack thread: " . $input;
        }

        return $output;
    },
],
```

The handler function receives:
- `$input`: The value from the Asana field
- `$output`: The current output row being built
- `$transformer`: The CSVTransformer instance, providing access to helper methods
